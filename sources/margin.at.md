# Margin — Web Annotation on AT Protocol

**URL:** https://margin.at

**Date accessed:** 2026-09-16

## What It Covers

Margin is a browser extension for annotating, highlighting, and bookmarking any web page. Built entirely on the AT Protocol.

## Key Information Extracted

- "Write in the margins of the web"
- Highlight text in any color, annotate selections, bookmark pages
- Uses CSS Highlights API — does not modify page DOM
- Annotations stored on your PDS as AT Protocol records
- Custom Lexicon schema: at.margin.note (W3C Web Annotation Data Model compliant)
- Features: collections, social discovery, tags & search, inline overlay, keyboard shortcuts, side panel
- Available for Chrome, Firefox, Edge, Safari, and iOS Shortcut
- Open source on GitHub
- Sign in with your AT Protocol handle — no new account needed
- One of the most innovative non-social apps on the Atmosphere

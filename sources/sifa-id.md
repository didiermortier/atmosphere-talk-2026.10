# sifa.id — Professional Identity on AT Protocol

**URL:** https://sifa.id

**Date accessed:** 2026-09-16

## What It Covers

Sifa ID is a professional identity platform built on the AT Protocol. Acts as a portable LinkedIn alternative.

## Key Information Extracted

- "A dynamic CV. Because so are you"
- Gathers activity from across AT Protocol apps into one profile
- Connected data sources: Bluesky, GitHub, RSS, ORCID, Tangled, Flashes, BookHive
- Endorsements: signed by real accounts on the AT Protocol, traceable and verifiable
- Each profile doubles as a standalone website at page.sifa.id
- Company pages available
- Import LinkedIn profile to get started
- Hosted in Germany (EU jurisdiction)
- Supports custom domains as handles
- Free while in alpha
- "Ditch LinkedIn" is a common user sentiment
- 5.0 rating on AT Store with 13 reviews

# PDS MOOver — AT Protocol Migration & Backup Tools

**URL:** https://pdsmoover.com

**Date accessed:** 2026-09-16

## What It Covers

A set of AT Protocol tools for PDS migration, backups, and account restoration. Made by @pds.dad.

## Key Information Extracted

- **Moover**: migrate to a new PDS
- **Missing Blobs**: find missing pictures/videos from previous migrations
- **Backups**: free automated backups stored on PDS MOOver servers
- **Restore**: restore from backups if needed
- **Turn Off**: deactivate old account after migration
- Stats: 251 migrations completed, 4,078 repos backed up, 1.7M+ blobs, 807.5 GB total blob size
